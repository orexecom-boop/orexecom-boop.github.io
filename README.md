# Odesskaya Banda

Сайт викладача музики **Юліанни Олегівни** — вокал, фортепіано, сольфеджіо.
Онлайн та студія на Таїрова, Одеса.

## Відкрити локально

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер:

```bash
npx serve .
```

## GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Сайт з’явиться за адресою `https://orexecom-boop.github.io/odesskaya-banda/`
